# Product image credits

The 12 thumbnails in this directory are the catalog images for the adversarial webshop
(`ecommerce-search`). They replace the inline-SVG colored tiles that stood in for upstream's
`via.placeholder.com` URLs, which an offline VM cannot reach.

All files were downloaded from Wikimedia Commons, then padded to a square on white and resized
to 400x400 JPEG. Three were cropped first, to isolate the garment (the flannel shot also carried
a shotgun and boots; the denim shot is cropped below the chin so no face is shown). The crops and
rescaling are modifications in the sense of the CC licenses below.

Each entry gives the file it is used for, the Commons source page, the author as Commons records
them, and the license that file is under. CC BY-SA files remain under their own license; the rest
of this repository is Apache-2.0.
